# ComfyUI Qwen-Image-2512 Worker

[![RunPod](https://img.shields.io/badge/RunPod-Serverless-blue)](https://www.runpod.io)

ComfyUI serverless worker with Qwen-Image-2512 models pre-installed.

- Diffusion Model: qwen_image_2512_fp8_e4m3fn (19GB)
- VAE: qwen_image_vae (242MB)
